MECHANISM: A high-dimensional state vector is updated at each step by a leaky combination of its previous value and a nonlinear function of a fixed random linear map of the input plus a fixed random recurrent map of the previous state, where the recurrent map is a sparse random matrix with spectral radius near one so that the state forgets initial conditions and acts as a fading memory. Crucially the input and recurrent maps are never trained. Several such state modules are stacked so that each module is driven by the output of the previous module rather than by the raw input, and the states of all modules are concatenated into one feature vector together with the raw input and a constant. Only a final linear map from this concatenated feature vector to the target is learned, by minimizing squared reconstruction error with an added squared-norm penalty, which has the closed-form solution given by inverting a regularized feature-covariance matrix and multiplying by the cross term. At inference the system is run autoregressively, feeding its own predictions back as inputs to roll the forecast forward over many steps. The decomposition of one large state module into a sequence of smaller modules reduces the size of the fixed matrices and the operation and memory counts while preserving multi-scale temporal structure. Forecast quality is tracked by the horizon at which a normalized error first exceeds a threshold and by image-similarity and error metrics computed against reference trajectories generated from chaotic ordinary differential equations and from discretized partial differential field equations.
