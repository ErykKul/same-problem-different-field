MECHANISM: A discrete integer-valued quantity indexed by successive periods evolves by a first-order recurrence in modular arithmetic: each new value equals the previous value plus a fixed increment plus several correction terms, all reduced modulo a fixed base. The correction terms are indicator functions that activate on regular sub-cycles tied to divisibility conditions of the period index. The goal is to replace iterating this recurrence with a single closed-form expression. The derivation first solves the simplified recurrence without corrections, exploiting that the quantity returns to the same value after a fixed cycle length, giving a linear expression in a cyclic index reduced modulo the base. The accumulated correction terms are then summed in closed form by counting how many activation events occur up to a given index; each cumulative count is expressed using floor-division of the index, and one nontrivial periodic pattern is matched to a floor-of-rational sequence and proved equivalent to alternative forms by exhausting residue classes. Combining the base solution with the closed-form correction sums yields an explicit formula for the quantity using only floor divisions and a modular reduction. A separate index-mapping function converts a calendar position into a linear day count via floor-division corrections for unequal segment lengths. A piecewise periodic generator with two interleaved cycle lengths is then composed with these to give the final quantity for any position, and a further difference-based adjustment is derived to remove discontinuities at period boundaries. The construction is validated by direct substitution and worked numeric tables, and an explicit procedural implementation is given.
