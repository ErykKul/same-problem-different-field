MECHANISM: The computational core derives an upper bound on the constructive depth of an entity that can appear in sufficient repeated copies without an external promoting mechanism, in a space where new entities are built only by recursively combining pairs of previously built entities. A complexity measure is assigned to each entity type as the minimum number of pairwise combine operations along a shortest construction path, equivalently the fewest internal nodes of a directed acyclic construction graph whose leaves are elementary units and whose final node is the entity. Assuming a fixed branching multiplier for how many new entities each combine step can yield, the number of distinct reachable entities grows super-exponentially with the number of steps. Under uniform exploration with no promotion, the expected count of any one entity type produced in a given number of steps is modeled as the total population times an exponentially decaying function of the step count. Setting this expected count equal to a fixed minimum detectable copy threshold and solving gives a closed-form bound on the maximum depth observable, scaling only logarithmically with population size. The argument is shown insensitive to the precise decay form, holding for any finite recursively built combinatorial space. A separate aggregate quantity is then defined by summing, over observed types present above one copy, the copy count weighted by an exponential of the depth measure, derived as a continuum limit of a per-step virtual-multiplicity growth model, yielding a scalar density of accumulated selection per observed entity.
