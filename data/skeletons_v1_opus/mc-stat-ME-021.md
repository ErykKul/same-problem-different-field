MECHANISM: A target scalar response is an unknown smooth function of a vector input plus zero-mean, possibly input-dependent noise, and the function lies in a Holder smoothness class. A fixed external black-box function approximating the target is available only through its outputs. The method estimates the additive discrepancy between the target and the external function and adds it back as a correction. To stabilize this, the external function is first passed through a deterministic local-smoothing operator that truncates its increment around each reference point to a Holder envelope set by two tuning parameters. The discrepancy is then estimated nonparametrically by a local kernel average: for each query point, responses minus the smoothed external prediction are averaged over sampled inputs within a bandwidth window. A finite-sample risk bound decomposes the integrated squared error into a squared-bias term governed by the smoothed discrepancy's local smoothness and a variance term inversely proportional to local sample counts. Minimizing the variance over the input-sampling density yields an optimal density proportional to the local noise scale, so the budget is allocated by first spending a fraction to estimate the noise scale by a kernel estimator and then drawing inputs from the estimated density by rejection sampling. The two smoothing parameters are chosen by held-out validation over a grid by minimizing squared prediction error. The achieved rate is shown to match a derived minimax lower bound, and the procedure is proved never to be worse in order than using target samples alone.
