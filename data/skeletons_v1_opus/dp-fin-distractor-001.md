MECHANISM: A value function defined over a state space and indexed by discrete time points is computed by stepping backward from a terminal condition. A large ensemble of independent state trajectories is first generated by repeatedly applying a stochastic transition map driven by random inputs. At the final time the value is set equal to a known terminal payoff function of the state. At each earlier time, a parametric nonlinear approximator (a composition of an affine map, a piecewise-linear thresholding nonlinearity, and a second affine map) is fitted to the current value estimates by minimizing mean squared error over the ensemble. The fitted function is then used to compute a one-step conditional expectation of the next value given the current state, which serves as a continuation estimate. The new value at each point is taken as the pointwise maximum of an immediate payoff and this continuation estimate. The recursion repeats until the initial time, yielding the value at the root. Because the approximator decomposes into a weighted sum of thresholded affine units whose conditional expectations are available in closed or fast form, the continuation expectation reduces to a weighted sum of elementary expectations. A convergence argument bounds the approximation error uniformly via a universal approximation property combined with the tower property of conditional expectation. Auxiliary lower and upper bounds on the root value are obtained from a suboptimal stopping policy and from a dual martingale construction.
DOMAIN: quantitative finance, derivative pricing and hedging
STRUCTURE: dynamic programming
DATA_OBJECT: sequence or time-series
INFERENCE: sampling or Monte-Carlo
PROBLEM_FORM: estimation
DISTRIBUTION: continuous; gaussian
COMPLEXITY: convergence rate
