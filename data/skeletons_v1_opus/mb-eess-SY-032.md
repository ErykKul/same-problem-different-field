MECHANISM: A set of source-to-sink flow magnitudes and a vector of behavioral parameters are jointly estimated so that the output of a forward simulator matches aggregate observations. The forward map has two nested stages: an inner fixed-point stage that, given the flow magnitudes and parameters, computes an equilibrium allocation of flow across alternatives using nested proportional-assignment rules with log-sum aggregation across hierarchical choice levels, solved by iterative averaging; and an outer loading stage that converts the allocation into observable aggregate quantities through a non-closed-form dynamic propagation. The estimation is posed as minimizing a weighted sum of squared discrepancies between simulated and observed aggregate quantities, restricted to observed coordinates by selection matrices. The problem is cast on a computational graph and solved by gradient descent: a forward pass evaluates the nested simulator and the loss, and a backward pass computes the gradient of the loss with respect to the unknowns by the chain rule through each stage. Because the propagation lacks a closed form, the per-stage Jacobians are derived and assembled explicitly rather than by automatic differentiation, then handed to an adaptive first-order optimizer. After convergence, a hypothesis test on individual parameters is built using a quadratic-form statistic from estimated curvature and gradient information to assess whether each parameter differs from a null value. The framework handles missing observations and scales to large instances.
