MECHANISM: A set of irregularly located events in a bounded planar region is modelled as a realization of an inhomogeneous point process whose log-intensity is a linear combination of many spatially varying coefficient functions multiplied by attribute fields. Each spatially varying coefficient is expanded in a two-dimensional multi-resolution orthonormal basis built as tensor products of a coarse scaling generator and oriented detail generators at successive dyadic scales, so that each basis-weighted attribute becomes a new localized regressor indexed by scale, orientation, and tile. The continuous-domain log-likelihood, consisting of a sum over events minus an integral of the intensity, is approximated by augmenting observed points with a dense set of background nodes carrying area weights, turning the objective into a weighted count-regression log-likelihood with a fixed offset. A separable orthonormal transform builds the enlarged design in near-linear time. The negative penalized objective adds either an absolute-value penalty or a smoothly clipped penalty on the basis weights, and is maximized by cyclic coordinate descent along a decreasing penalty path. The penalty level is chosen by minimizing a complexity-penalized information criterion using the effective sample size. Nonzero weights define active sets globally and, by checking which tiles cover each location, locally, yielding scale- and place-specific selection. Accuracy is assessed by simulation against alternative penalized estimators using selection rates and coefficient-surface error.
