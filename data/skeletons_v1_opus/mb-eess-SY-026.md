MECHANISM: A source quantity evolves as a finite-state continuous-time jump process with a known generator, and a collection of agents each hold a stored copy tagged by a version index. Copies are refreshed by direct pushes from the source and by pairwise exchanges among agents, where an agent adopts an incoming copy only if its version is fresher than the local one, so the freshest copy may still disagree with the current source state. Two scalar correctness functionals are defined: the expected fraction of agents in a subset whose copy matches the source, and the correctness of the freshest copy in a subset. The joint state of the source mode and the per-agent correctness-and-freshness vector is treated as a piecewise-constant stochastic process with instantaneous resets, and each event type is assigned a mode-dependent rate. For a chosen test functional, the stationary condition that its expected time-derivative vanishes is written as a balance equation summing rate-weighted reset increments over all event types. Applying this to mode-tagged correctness functionals yields, for each subset size, a coupled pair of linear equations relating the subset-size quantity to the next-larger subset size, producing a matrix-valued backward recursion solved by repeated small matrix inversions from a closed-form terminal condition. The average-correctness quantities are then obtained from another small linear system driven by the freshness quantities. Limiting regimes are derived by rescaling the linear systems as individual rates grow large or vanish.
