MECHANISM: A continuously deformable body is driven by a low-dimensional actuation vector, and the goal is to regulate both its full configuration and a tip position to references without an analytical dynamics model. The configuration is first encoded from several two-dimensional projections: each projection is segmented to a centerline point set, and a piecewise low-degree polynomial parametric curve is fit to the points by solving a per-segment linear least-squares problem for the free control points; stacking and vectorizing the control points across views yields a compact state vector. Two unknown first-order vector fields, one for the configuration state and one for the tip state, are each approximated by a parametric nonlinear map and treated as initial-value problems, so a predicted future state is obtained by numerically integrating the learned field forward in time, and the maps are trained by minimizing the discrepancy between integrated and observed next states under piecewise-constant input. For control, the tracking error is required to decay exponentially via a first-order linear error dynamics, and the state rate is locally related to the input rate through a sensitivity (Jacobian) matrix, so the commanded input rate is the pseudo-inverse of the Jacobian times the reference rate plus a proportional error term. The Jacobian columns are estimated by central finite differences obtained from perturbing each input component and re-integrating the learned field. A secondary objective repels the nearest curve point from an obstacle by an escape velocity along the outward direction, mapped to a state rate through an analytic curve Jacobian and gated by a warning-distance threshold, with a multi-view switching rule that activates only when needed. The configuration, tip, and avoidance commands are superposed into a single input-rate law.
