MECHANISM: A classifier over short discrete sequences is trained when only a tiny fraction of examples carry labels. Raw continuous recordings are first high-pass filtered, then reduced to a sparse representation by zeroing all amplitudes inside a threshold band and keeping only the rare large-magnitude events, and the result is cut into fixed-length non-overlapping windows that become the input units. The bulk of windows are left unlabeled. Two parameterized networks are trained adversarially: a generator maps a random latent vector through projection, reshaping, and transposed-convolution layers into a synthetic window, while a discriminator both distinguishes real from synthetic windows and assigns one of several class labels. The discriminator processes each input by partitioning the sequence into fixed local blocks and applying multi-head self-attention within each block, alternating the block boundaries by a cyclic shift between layers so information crosses block edges, without any resolution-reducing merging, then pools and maps to a categorical output via a normalized exponential layer. The shared objective combines a supervised term over the few labeled windows with an unsupervised real-versus-synthetic term over the rest, so unlabeled and generated data shape the representation. Parameters are updated jointly by stochastic gradient steps; key architectural and step-size settings are chosen by a sequential model-based search. The whole pipeline is repeated with re-randomized splits to report averaged performance and variability.
