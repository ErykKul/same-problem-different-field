MECHANISM: Compress each high-dimensional frame into a low-dimensional latent that additively separates a static identity component from a time-varying state component. Model a sequence of these latents autoregressively, factorizing the joint distribution so each element depends on past elements and on a per-step external conditioning bundle. Train a generative transport map: corrupt each sequence element by interpolating between data and reference noise at an independently sampled per-element noise level, and regress a learned vector field toward the displacement from noise to data, minimizing expected squared error. Enforce causality with a block-structured attention mask that lets elements within a block attend mutually but only to earlier blocks, relaxed by a small look-ahead window for temporal smoothness, and reuse cached key-value states for streaming generation. Fuse multiple conditioning streams through stacked cross-attention layers. After base training, add a preference-alignment objective: form preferred/less-preferred output pairs (ground-truth versus a degraded variant produced by dropping part of the conditioning), and minimize a log-sigmoid contrast of the log-likelihood ratios of the two outputs against a frozen reference model, combined additively with the original regression loss. Generate at inference by autoregressive rollout, integrating the learned vector field with a small number of solver steps under guidance. Evaluate with synchronization correlations, diversity/variance measures, distributional distances between generated and real samples, and paired human preference ratings.
