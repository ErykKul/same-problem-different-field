MECHANISM: Multiple agents each independently solve an inverse problem: recover the latent scalar value function over a discrete state-action support that best explains observed expert sequences, using a maximum-entropy formulation with a linear feature parameterization, yielding a local parameter vector by gradient-based optimization under a limited budget. The central step fuses these heterogeneous local value functions in a geometry-aware way rather than by naive parameter averaging. Each local function is explicitly evaluated on the shared support lattice, then shifted and normalized to become a nonnegative probability measure of value mass. A consensus measure is computed as the barycenter under an entropically regularized optimal-transport distance, i.e. the measure minimizing the average regularized transport cost to all client measures; this is obtained by iterating alternating scaling (Sinkhorn-type) updates of dual vectors over the cost kernel until convergence. The fused measure is then projected back into the linear feature basis by least squares to recover a global parameter vector that lightweight clients can use without sharing raw trajectories. A theoretical analysis establishes a stability/contraction guarantee: the barycentric aggregate contracts toward the true value function with a parameter-error bound under bounded local estimation error, and is shown to be more faithful than coordinate averaging. Empirical comparison on discrete and continuous-control benchmarks tests transferability and stability of the fused estimate against the averaging baseline.
