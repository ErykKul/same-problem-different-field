MECHANISM: A continuous-time state vector evolves under dynamics that are affine in an input and contain an unknown constant parameter vector entering through a known regressor, with an inequality constraint defining an admissible region. The method first lifts the constraint into an extra scalar coordinate via a smooth monotone map of the constraint margin that diverges at the boundary, so that staying admissible is equivalent to that coordinate remaining finite; this augments the state with a barrier coordinate whose evolution is derived by differentiating the map. An observer for the barrier coordinate is built, and its error together with the parameter error is driven by an estimator that integrates past input-output increments over a sliding window into a stored history of regressor blocks, updating the parameter via a projected, gain-weighted residual law whose gain follows a least-squares recursion; admission of new history entries maximizes the smallest eigenvalue of an accumulated information matrix, replacing a persistent-excitation requirement by a finite-interval rank condition. For the augmented system an infinite-horizon quadratic cost is posed, whose optimal value function satisfies a first-order partial differential stationarity condition; the minimizing feedback is expressed in closed form through the value gradient. Because the equation lacks a closed-form solution, the value function is approximated as a linear combination of basis functions, and two adaptive weight vectors (a critic and an actor) are updated by gradient laws on the squared residual of the stationarity equation, evaluated at the current state and at extrapolated virtual states. A single composite quadratic-type energy function of all errors is shown to decrease, giving uniform ultimate boundedness, stability, and invariance.
