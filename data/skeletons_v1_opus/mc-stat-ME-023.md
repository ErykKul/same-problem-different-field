MECHANISM: The goal is to estimate, as a function of a continuous input level, the average of a counterfactual response over a population, when an unobserved variable confounds the input-response link but an auxiliary instrument is available. Identification uses weighting functions of the instrument and observed covariates whose conditional cross-association with the input stays bounded away from zero; existence of such a function at a level is shown equivalent to a divergence-based relevance condition, and local stability lets one cover any compact range by finitely many neighborhoods each served by one weighting function. Under an additivity condition that rules out instrument-confounder interaction in the input model, the target equals the expectation of a ratio nuisance functional. Semiparametric theory yields the efficient influence function of a covariate-shifted version of the estimand, from which an augmented inverse-probability-weighted score with a mixed-bias (doubly robust) property is built whose conditional expectation given the input equals the target. Several nuisance functions (conditional means, a density ratio, the cross-association) are fit by flexible machine learners, with sample-splitting cross-fitting so that nuisance training is independent of score evaluation. The level-specific target is then recovered by a local linear smoother that solves a kernel-weighted least-squares fit of the score on the input near each level, with bandwidth chosen by cross-validation. Asymptotic analysis gives a rate that splits into a smoothing variance of order one over root sample times bandwidth, a squared-bandwidth bias, and a vanishing mixed-bias term, and establishes a centered limiting normal law enabling confidence intervals.
