MECHANISM: A predictive model parameterized by weights is updated incrementally over time from streaming unlabeled batches arriving at many separate units, where the data-generating distribution drifts per unit and over time. Because labels are unobserved, the loss is estimated by reweighting a precomputed class-wise reference loss with an estimated current label proportion vector, where the proportion is recovered by inverting a fixed confusion matrix applied to the model's predicted label histogram. Each unit's parameters are split into a shared block, periodically averaged across units weighted by sample count, and a private block kept local; both are updated by gradient descent on the estimated loss with a per-unit, per-step step size. The step size is set by a drift signal in a fixed interval: it linearly interpolates between a minimum and maximum according to a bounded magnitude of distributional change. The drift signal averages two components. The first compares the mean predicted class-probability vector of the current batch to that of the previous batch via one minus their cosine similarity. The second compares the mean of the per-sample length-normalized feature vectors of consecutive batches via a rescaled cosine distance. Both require storing only the previous batch summary, giving small memory cost. Theoretical analysis bounds the gap between the accumulated drift signals and the true accumulated distributional path length using calibration and Lipschitz constants, then derives a cumulative-loss bound relative to a per-step optimal comparator that scales with the accumulated drift, and shows a step-size choice attaining the optimal nonstationary rate.
