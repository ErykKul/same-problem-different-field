MECHANISM: Given a table of feature vectors paired with a continuous target observed over time, fit additive ensemble predictors by stagewise boosting. The first predictor is an ensemble of recursive-partition trees built sequentially: at each stage a new tree is fit to reduce a regularized objective combining a per-instance loss with a penalty on tree size and leaf magnitudes, using first- and second-order derivatives of the loss to score candidate splits via a gain criterion and to set leaf values, and the prediction is the sum of all trees. The second predictor is a generalized additive model in which the output is an intercept plus a sum of one-per-feature shape functions; these shape functions are learned by boosting in round-robin over features, repeatedly fitting each feature's function to the current residual and updating with a small step size, so the final prediction decomposes additively and each feature's contribution is directly inspectable. A stacked variant chains them: fit the additive model first, then train a tree ensemble on its residuals, and sum the two outputs. Train with an expanding-window temporal split and select hyper-parameters by grid search on held-out data. Forecast a multi-step-ahead value from forecasted (not realized) inputs, evaluate with absolute and squared error and a coefficient-of-determination, benchmark against a last-value naive predictor, and read off global feature importances and per-feature response curves, including a stratified evaluation on rare large-deviation events.
