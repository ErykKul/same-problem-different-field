MECHANISM: The goal is to attribute a model's overall explanatory quality fairly among its individual input variables. The setup treats the input variables as players in a cooperative allocation problem and a goodness-of-fit number as the value secured by any subset of players. For each variable, its allocated importance is the average, over all subsets not containing it, of the gain in fit obtained by adding it, with combinatorial weights that depend on subset size; this requires fitting the model on every one of the exponentially many subsets of variables. The paper characterizes which fit functions make this allocation interpretable: the fit must vanish on the empty subset, be nondecreasing as variables are added, and ideally be bounded above by one at the best-possible (saturated) reference, so the allocations are nonnegative, sum to the full-model fit, and can be read as relative and absolute shares. It is shown by derivation that an information-divergence-based fit, defined as one minus the ratio of the divergence of the fitted model to that of the constant-only model, satisfies these requirements for a broad exponential-family regression class, reduces to the classical variance-explained ratio in the linear case and to a log-likelihood-ratio index in the binary case, and equals the fraction of deviance explained. Each subset model is fit by maximum likelihood. The work further shows that using an unnormalized log-likelihood as the value function breaks the additive-decomposition property, yielding only an ordinal ranking, and quantifies the linear rescaling linking the two. Several count and binary regression examples illustrate the resulting allocations.
