MECHANISM: A discrete-time recursion advances a state vector through a known deterministic update map driven at each step by an independent random perturbation whose distribution is unknown, and the goal is to certify that the trajectory stays inside a prescribed compact set over a finite number of steps with high probability. The method searches for a scalar certificate function over the state space, parameterized linearly in unknown coefficients, that satisfies sign conditions on a boundary region together with a one-step decrease/supermartingale-type inequality under the random perturbation. Because the perturbation distribution is unknown, the universal constraint over all perturbations is replaced by constraints evaluated only on a finite set of independent identically distributed samples, yielding a sampled feasibility/optimization program whose objective approximates the spatial integral of the certificate by averaging over state grid points. The central question is how well a certificate satisfying the empirical constraints generalizes to the true expectation, i.e. bounding the gap between empirical and true violation probability. Three different generalization tools are applied: a combinatorial-dimension bound giving an explicit sample count for uniform deviation, a scenario-style bound exploiting linearity in the coefficients to get a stronger state-uniform guarantee with fewer samples, and a complexity-of-function-class (averaged-random-sign) bound for the variant that enforces the constraint only in expectation. Each yields an explicit sample-complexity inequality relating sample size to the parameter dimension and to the target tolerance and confidence levels. The one-step guarantee is composed across the horizon to give a finite-horizon probability lower bound that degrades geometrically with the number of steps. The certified sublevel/superlevel region acts as an approximate forward-invariant set, applied recursively online. Numerical instances are solved as semidefinite programs via sum-of-squares relaxations of the polynomial certificate.
