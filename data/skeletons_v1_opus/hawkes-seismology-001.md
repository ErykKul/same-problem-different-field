MECHANISM: A catalog of events is recorded as points in time, space, and magnitude, and is modeled by a history-dependent occurrence-rate function equal to a constant baseline term plus an additive sum of decaying contributions from all prior events. Each past event's contribution is a separable product of a magnitude-dependent productivity factor, a decaying function of elapsed time, and a decaying function of spatial distance, with a small set of governing scalar parameters. The novelty is to let these parameters vary across space rather than be uniform. Estimation treats each event's origin as a latent label, either background or triggered by a specific earlier event, and alternates two steps: given current parameters it computes the posterior probability that each event is background or triggered by each predecessor, then given those probabilities it maximizes the expected complete-data likelihood to update the parameters. To obtain spatial variation the domain is randomly partitioned many times into cells via stochastic spatial tessellations, the parameters are fit independently per cell within each partition, and each fitted partition is scored by a penalized-likelihood criterion that trades fit against the number of free parameters. The many scored partitions are combined into a weighted ensemble so that a smoothly varying parameter field can be read off at any location. The procedure is first validated on a synthetic catalog generated with known parameters to confirm faithful recovery, then applied to real data and the inferred spatial parameter field is correlated against an external covariate.
