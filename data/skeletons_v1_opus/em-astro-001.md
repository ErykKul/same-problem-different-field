MECHANISM: A collection of noisy vector-valued profiles is observed for many entities, each measured over a set of ordered bins with an associated covariance. A parametric template for the underlying profile is posited as a function of a few shape parameters, and a transformed/projected version of this template is obtained by integrating it over an auxiliary displacement variable. Each entity is modeled as a two-component mixture: with some probability it is correctly aligned and with the complementary probability it is offset by a displacement drawn from a one-parameter radial distribution, so its expected profile is a weighted convolution of the template against that displacement law. A per-entity likelihood is written as a multivariate normal in the residual between the observed profile and the mixture-expected profile, using the entity covariance. The full likelihood is formed as a product of these per-entity likelihoods under one shared parameter set, in contrast to a baseline that first averages all profiles and fits a single pooled likelihood. Priors are placed on all shape and mixture parameters and the joint posterior is explored by a stochastic sampler that also estimates the evidence. Marginal posteriors for the two mixture parameters (the offset fraction and the offset scale) are extracted by integrating out the shape parameters. Goodness of fit is summarized via a quadratic residual statistic compared to its reference distribution. The two estimators are compared by how tightly and accurately they recover known injected mixture parameters across several configurations.
