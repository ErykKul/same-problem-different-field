MECHANISM: A binary outcome is modeled from a high-dimensional structured input (a multichannel sequence) plus a few scalar covariates, using a generalized additive structure under a fixed link. Instead of letting each raw input entry contribute its own function, the raw signal is first passed through a fixed pretrained high-capacity nonlinear map that emits a moderate set of scalar scores, each squashed by a sigmoid into a bounded value interpretable as a calibrated auxiliary probability. The transform-then-add model writes the linear predictor as a parametric linear term in the covariates plus a sum over the derived bounded predictors of an unknown smooth univariate function. Each smooth univariate function is expanded in a fixed-order polynomial spline basis with data-driven knots placed at empirical quantiles, so the additive model becomes linear in unknown basis coefficients. A redundant basis degree of freedom per function is removed and a global intercept added for identifiability. The coefficients and covariate weights are fit by minimizing the negative log-likelihood of the binary outcome under the logistic link plus squared-norm penalties on both the linear weights and the spline coefficients, a penalized convex objective solved by standard solvers, with penalty strength and basis count chosen on held-out data by a discrimination criterion. The pretrained score map is itself obtained beforehand by linear probing followed by regularized fine-tuning against many auxiliary categorical labels. Estimated component functions are centered to integrate to zero to give interpretable partial effects, and uncertainty is summarized by resampling.
DOMAIN: ECG-based structural heart disease detection
STRUCTURE: neural network
DATA_OBJECT: sequence or time-series
INFERENCE: maximum likelihood
PROBLEM_FORM: prediction or classification
DISTRIBUTION: binary; logistic
COMPLEXITY: polynomial iterative
