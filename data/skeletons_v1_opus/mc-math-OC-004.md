MECHANISM: The method recasts the fitting of a layered system of interconnected binary-valued units as the search for an assignment of binary parameters that satisfies a large set of logical activation constraints. Each unit applies a sign threshold to a weighted sum of its predecessors, and a bit-expansion identity is used to encode "the signed sum is positive" exactly as the most-significant bit of an auxiliary binary expansion. Replicating these activation constraints across every training example and every unit yields a constrained feasibility problem over binary decision variables. Each equality constraint is turned into a squared penalty term, and product terms between binary variables are linearized via auxiliary variables and their own penalty terms, producing a single quadratic objective in binary variables whose global minimizers are exactly the feasible assignments. Two extra quadratic penalty terms are added: one rewarding larger margins of the pre-activation sums (a proxy summed over examples), and one supplying tunable linear biases on individual parameters. An iterative scheme repeatedly removes a random subset of units, solves the reduced quadratic problem on a batch, and updates the linear biases by a rule that decays with the count of violated constraints. The resulting quadratic binary objective is minimized by a stochastic temperature-lowering local-search sampler run with many parallel replicas. Solution quality is read off from the residual penalty value and from accuracy on held-out items.
