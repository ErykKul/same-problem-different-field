MECHANISM: A collection of entities, each described by several scaled numerical attributes, is treated as a point cloud in a multidimensional space, and the goal is to summarize its shape as a small two-dimensional graph without projecting the coordinates. A single radius parameter is fixed. The construction proceeds greedily: an uncovered point is selected as a landmark, all points within the fixed radius of it are marked covered, and the procedure repeats by selecting a new landmark from the still-uncovered points until every point belongs to at least one neighborhood. Each neighborhood becomes a node, recording exactly which points it contains; node size is set proportional to the number of contained points to convey local density. Whenever two neighborhoods share at least one point, an edge is drawn between their nodes, so overlaps in the original space become connections in the summary graph. Each node is then annotated by a summary statistic, typically the average of an auxiliary attribute over its members, which is mapped to a color. Because membership is retained, any node can be linked back to the underlying entities and summarized with within-node dispersion statistics. The whole construction is repeated across several values of the radius to check that the recovered local and global structure is stable, since smaller radii give more, smaller neighborhoods and larger radii merge them. The output is an abstract graph whose layout axes carry no meaning but whose connectivity and coloring reflect the data's structure.
