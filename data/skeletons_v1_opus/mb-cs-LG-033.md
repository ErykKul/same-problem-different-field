MECHANISM: A generative model is trained to synthesize two heterogeneous data types by reversing two distinct corruption processes that share a common parametric backbone. For discrete token sequences, a forward process independently replaces each token by a special placeholder with a time-dependent probability, and a network is trained to predict the original tokens at placeholder positions by minimizing a time-integrated, reweighted reconstruction loss; generation iterates the learned reverse transition from a fully corrupted sequence, decoding placeholders progressively. For continuous-valued latent arrays, a forward process linearly interpolates between data and noise along a time variable, and a network is trained to regress the constant displacement (velocity) from noisy intermediate states by minimizing squared error; generation integrates the learned velocity field as an ordinary differential equation from noise to data. The two corruption-specific predictors are kept as separate specialized branches to avoid gradient interference, but they read and write through one shared attention backbone so the two data types can condition on each other. The shared attention is restricted to full attention within same-type blocks and causal attention across blocks, so fixed conditioning blocks form a reusable cached prefix and are not recomputed each generation step. A data-side augmentation stochastically appends termination markers or truncates targets during training so the decoder learns variable output lengths without changing the architecture. At inference, conditioning blocks are cached once and response blocks are generated and appended iteratively until a termination marker is emitted with high confidence. A tunable confidence threshold trades decoding speed against accuracy by controlling how many positions are committed per step.
