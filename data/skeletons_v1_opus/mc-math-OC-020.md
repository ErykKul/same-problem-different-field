MECHANISM: A large coupled dynamical system is described by differential equations for evolving state quantities together with algebraic constraints relating auxiliary quantities, assembled hierarchically from independently defined submodels into one unified set of equations and parameters. Given inputs, the trajectories of the state quantities over time are obtained by numerically integrating the differential-algebraic system, after first solving the algebraic relations to obtain consistent initial values. The system is built symbolically so that exact derivatives of any computed output with respect to inputs and parameters are available by algorithmic differentiation, enabling composite simulation procedures, including a multi-scale reduction in which a fast subsystem is solved to a stationary balance at selected time points and reinserted as a time-varying input to the slower subsystem. Unknown parameters and initial conditions are fitted by minimizing a discrepancy between predicted and observed outputs, formulated as a constrained optimization over the dynamics. An optimal-control problem then selects a time-varying input trajectory to optimize an integral-plus-terminal objective subject to the dynamics and to bound constraints on states and inputs. This problem is transcribed into a finite-dimensional nonlinear program by parameterizing the input over a finite number of intervals and evaluating the differentiable simulation, then solved by gradient-based methods. A receding-horizon controller repeatedly re-estimates parameters from new measurements, re-estimates the current state, re-solves the optimization over the remaining horizon, and applies only the first input increment.
