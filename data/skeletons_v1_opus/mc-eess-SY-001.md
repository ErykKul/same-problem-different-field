MECHANISM: A continuous transfer function is specified in a normalized complex-frequency variable as a repeated complex pole raised to a real exponent, parameterized by three real constants. From this closed form, analytic expressions are derived for a set of summary descriptors of the response, both magnitude-based (peak location, several bandwidth-based sharpness factors, curvature at the peak) and phase-based (group delay at the peak, accumulated phase), each written explicitly as a function of the three constants using gamma-function identities. Selected dimensionless ratios of these descriptors are formed and shown to depend on essentially a single constant, which makes them well-conditioned for inversion, whereas individual descriptors confound two constants and yield an ill-posed inverse. The inverse problem of recovering the constants from reported descriptor values is then solved sequentially: one constant is read off the peak location, a second is obtained by solving a single nonlinear scalar equation in a ratio that isolates it, and the third is recovered from a remaining linear equation. Sensitivity of each descriptor to each constant is analyzed to decide which reported quantities give reliable point estimates versus only bounds. The same closed-form descriptor-to-constant relations are shown, by numerical comparison of relative errors, to approximate several related realizable filter families in the peak region under a small-damping regime. Reported empirical ratios then yield bounds and point estimates for the constants.
