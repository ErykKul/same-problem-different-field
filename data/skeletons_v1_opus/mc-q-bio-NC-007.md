MECHANISM: A two-module function approximator is built so that a small low-dimensional code controls how a high-dimensional input is processed for a binary judgment. One module maps a compact real-valued code through layers into per-layer gating signals bounded between zero and one; the other module passes features extracted by a fixed pretrained encoder through stacked layers, where at each gated layer the layer activations are multiplied element-wise by the corresponding gating signal before the next linear map. The final layer outputs a two-way decision trained by cross-entropy against a yes/no target, where positives pair an input with its own code and negatives pair it with a mismatched code. Training alternates two phases: holding the codes fixed while updating all layer weights by back-propagated gradients, then holding the weights fixed while updating only the codes by the same gradients, repeated until accuracy saturates, with small injected noise for robustness. After training, the learned codes form a structured low-dimensional space whose geometry is probed by an entropy of per-class response counts, by clustering under a cosine dissimilarity, and by comparing pairwise-dissimilarity matrices against external reference dissimilarity matrices via rank correlation with permutation tests. Knowledge is transferred between two independently trained instances by fitting a separate regression network that maps one instance's code space onto the other's, then evaluating whether a mapped held-out code drives correct judgments. The same code-only optimization, augmented with a repelling penalty, learns a code for an unseen class from few examples. The fitted representations are correlated with measured response patterns from an external source using partial rank correlation against a sensory baseline. The core computed object is the gated classifier and its learned code geometry.
