MECHANISM: Two latent vectors are associated with the rows and columns of a large binary observation matrix, and the probability of each binary entry is modeled by a sigmoid (logistic) transform of a bilinear form in the two latent vectors, optionally with a lower-asymptote offset parameter per column. Parameters are fit by maximizing the joint likelihood, which is non-convex jointly, so an alternating optimization fixes one latent set and optimizes the other, then swaps, iterating to convergence. Each half-step decomposes into many independent low-dimensional convex sub-problems, each equivalent to fitting a logistic loss summed over an extremely large number of points whose only difference across instances is the sign pattern of the labels. To make each sub-problem scale sublinearly in the number of points, the method builds a small weighted subset (a summary) that provably approximates the full summed loss to within a multiplicative factor for every parameter choice. The summary is constructed by importance sampling with probabilities proportional to upper bounds on each point's worst-case contribution, here the square root of statistical leverage scores plus a uniform floor. A key observation is that the leverage scores depend only on the spanned subspace and are invariant to per-point sign flips, so a single summary remains valid across all alternating iterations, with size inflated only logarithmically by a union bound. The summary size is bounded via a total-sensitivity argument combined with a bound on the combinatorial dimension of the induced function class. The construction is extended to the harder case with an extra bounded non-convex sigmoid term by splitting points by label and bounding both sensitivity types separately. A parameter-recovery guarantee bounds the deviation between the full-data optimum and the summary optimum. Empirically, runtime and memory drop sharply while estimates remain close.
