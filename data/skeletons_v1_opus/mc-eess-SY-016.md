MECHANISM: An agent interacting with a stochastic sequential-decision process learns a parametric stochastic action rule by alternating value estimation and rule improvement on stored transition tuples. Unlike a point-valued value estimator, the value network outputs a full conditional probability law (parameterized by a mean and a spread) over the one-step bootstrapped return, capturing irreducible target variability from transition noise and ongoing rule changes. The estimation target for each sampled transition is the immediate reward plus a discounted next-state value that is made deliberately conservative by subtracting a constant multiple of the predicted spread, plus an entropy term; the network is fit by minimizing the negative log-likelihood of this target under the predicted law. Assuming the value law is sub-Gaussian, an analytic upper bound is derived showing that the gap between the expected backed-up value and the backed-up mean is controlled by the predicted variance, so a variance-proportional downward shift provably removes the positive bias; the backed-up operator is shown to contract. The same conservative value feeds the rule-improvement gradient step so evaluation and improvement share an objective. A slowly tracking copy of the value network supplies bootstrapped targets for stability, hidden-layer normalization and random unit-dropping regularize the single network, and a temperature coefficient is auto-tuned as the dual variable of an entropy constraint. Performance is assessed over repeated random seeds on benchmark control tasks.
