MECHANISM: A scalar-valued function of a state variable and time is sought as the solution of a second-order parabolic partial differential equation derived from a no-arbitrage self-financing replication argument. Starting from a wealth identity and a budget/flow equation for the holdings, the increment of the portfolio value is expanded using the chain rule for a diffusion driven by Brownian motion, and a hedge coefficient is chosen to cancel the stochastic term. Substituting the hedge ratio and the financing balances yields a deterministic evolution equation whose lower-order term is piecewise-defined, depending on the sign of an auxiliary balance, so the operator is nonlinear and continuous but only piecewise differentiable. The state-time domain therefore splits into two regions, each governed by a linear parabolic operator with different coefficients, separated by an unknown free boundary across which the solution and its first derivative are required to be continuous. The equation is discretized on a structured grid in the state and time directions and advanced backward from a terminal payoff using an implicit second-order time-averaging scheme that produces tridiagonal linear systems at each step. The location of the free boundary is found by an inner fixed-point iteration that updates which coefficient regime applies at each node. For the variant with an early-exercise constraint, a projected over-relaxation sweep enforces an obstacle condition while simultaneously iterating the regime term. Boundary closures impose a vanishing second derivative at the grid extremes so the scheme remains tridiagonal regardless of the terminal payoff shape. Distinct sign conventions of the lower-order term produce two slightly different solutions whose gap quantifies an asymmetry between two opposing positions. In limiting parameter cases a closed-form expression involving the standard normal cumulative function is recovered and used to validate the numerical solver.
