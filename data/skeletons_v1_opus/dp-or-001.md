MECHANISM: A system is given as a directed graph whose nodes carry either stochastic-transition or choice semantics, with weights and a designated terminal subset. The goal is to compute a fixed point of a local update operator that assigns to each node a quantity equal to the weighted aggregate of its successors' quantities, optimizing over choices at choice nodes. The baseline procedure starts from upper and lower bounding vectors and repeatedly applies the local update simultaneously to all nodes, producing a monotone sequence that converges to the fixed point. A discrete graph preprocessing first partitions nodes into layers by shortest-distance to the terminal set using breadth-first traversal, then selects a small separating set of nodes whose removal bounds the layer count. For each selected node a value is hypothesized and verified: the hypothesis is fixed as a terminal weight, the reduced instance is solved to tighter tolerance, and a single local update tests whether the hypothesis is a valid lower or upper bound by monotonicity. Verification proceeds recursively over the selected set, bisecting each node's bounding interval until the gap is below tolerance. The selection guarantees the residual instance has few layers, so the bounding-vector iteration on it needs only sub-exponentially many updates. Correctness follows from invariants that the maintained interval brackets the true value, and termination from monotone interval shrinkage. Complexity is analyzed for the preprocessing steps and for the total number of local updates.
