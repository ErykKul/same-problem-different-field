MECHANISM: Given a large ordered collection of high-dimensional configurations sampled along a trajectory, the goal is to estimate the probability that continuing the sampling would yield a configuration farther than a threshold from every configuration seen so far, as a function of that threshold. The estimator rests on a frequency-of-frequencies identity: the probability mass of as-yet-unseen items equals the count of items observed exactly once divided by the total count, where items are treated as distinct draws from a pool with an unknown number of types. To make near-duplicate configurations behave as distinct draws, the collection is thinned by a stride chosen so that consecutive retained configurations are effectively uncorrelated. The original method formed the full symmetric matrix of pairwise dissimilarities, built a hierarchical merge tree from it, cut the tree at increasing thresholds, and read off the count of singleton groups at each cut, but this required storing the whole matrix. The new method avoids the matrix: for each retained reference configuration it computes the dissimilarity to all others and keeps only the single largest value, producing one extreme value per reference. These per-reference maxima are sorted in descending order, and the item at rank i is assigned probability i over the total, which reproduces the singleton counts of successive tree cuts at linear memory cost. Repeating over offsets within the stride yields a family of curves whose spread quantifies estimation uncertainty. The stride itself is selected by computing extreme dissimilarities across pairs separated by growing lags and detecting where this growth saturates, using a piecewise-linear segmentation found by dynamic programming to pick the plateau.
