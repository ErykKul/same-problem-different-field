MECHANISM: A time-indexed directed graph with numeric node and edge attributes is embedded into a fixed sequence space over a global index of all entities, and each snapshot is encoded as a normalized complex-valued vector whose entries are a chosen function of the attributes under a context, with squared magnitudes read as activation weights. Between observations the vector evolves by a unitary operator obtained as the matrix exponential of a self-adjoint coupling operator assembled from Hermitian edge kernels and real diagonal node terms, giving norm-preserving prediction. A reference self-adjoint operator built from long-run aggregated structure is diagonalized to supply an interpretable latent basis, and any state is expressed by its coefficients in that basis. A divergence scalar per time index weights the outer products of the snapshot vectors into a positive semidefinite, self-adjoint aggregate operator that behaves like a weighted covariance over high-error states. Its leading eigenvectors define principal directions; expanding a direction in the entity basis and thresholding the loadings yields candidate subsets, each represented by an orthogonal projector. A subset is validated by an ablation test: project it out, renormalize, recompute the divergence, and check whether the average reduction is positive. For cross-instance comparison, each instance's latent coefficients are placed into a shared reference space through an index map and an orthogonal alignment transform, and operators and directions are carried over by conjugation, with adjoint maps projecting shared findings back to each instance's basis. The paper presents this construction without empirical evaluation.
