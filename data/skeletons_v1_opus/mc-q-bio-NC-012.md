MECHANISM: A multi-layer dynamical model maps an input sequence of discrete symbols to a class label, with each layer holding a hidden state that evolves in discrete time. The hidden state is organized as a tensor product of a feature subspace and a temporal subspace, so the recurrent update matrix is block-diagonal with identical blocks acting independently on each feature's temporal memory; the temporal block is constrained to be diagonal with a chosen spectrum of decay rates, turning the state into a bank of leaky integrators with heterogeneous time constants. A linear readout, restricted to a banded translation-invariant (Toeplitz-like) form, projects the decaying states into sequentially activated, time-shifted profiles; the readout is reshaped to a feature-by-time array, convolved with shared kernels, and max-pooled over the temporal axis to produce remapped features for the next layer. Parameters are fit by gradient-based minimization of a classification loss at a single reference timescale. To characterize the learned representation, pairwise correlations of population state vectors across time pairs are computed as a self-similarity matrix; sensitivity to context scale is probed by permuting the input at several block sizes, applying the inverse permutation to realign outputs, and measuring the correlation drop, with the half-maximum scale defining an integration window per layer. Linear receptive fields per unit are recovered by stimulus-triggered averaging at several hierarchical scales. The model is then tested for zero-shot generalization by feeding inputs temporally rescaled by large factors without retraining, and scale-invariance is verified by collapsing activity curves under normalized time.
