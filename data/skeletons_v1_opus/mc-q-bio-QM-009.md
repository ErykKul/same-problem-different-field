MECHANISM: Each instance is a three-dimensional point set of elements, each carrying categorical and continuous attributes, from which a graph is built by connecting every element to its nearest neighbors within a fixed distance cutoff. For each edge, geometric attributes are computed: the pairwise distance and the unit direction vector between the two endpoints. Node attributes are concatenated and projected through stacked fully connected layers with nonlinear activations into a compact latent embedding. Several attention layers then refine embeddings: for each ordered neighbor pair, an attention weight is formed by a learnable linear map applied to the concatenation of transformed endpoint features and edge features, passed through a nonlinearity and normalized over neighbors. Messages are aggregated as attention-weighted combinations, with a coupled update maintaining both scalar and vector quantities so that directional geometry is propagated. A second attention mechanism with a learnable query pools element-level representations into higher-level group representations by weighted summation. The pooled representations pass through a multilayer decoder producing, per group and per output category, a bounded score via a squashing activation, interpreted as a probability. Parameters are fit by minimizing a class-weighted sum over outputs of a binary log-loss, with weights inversely proportional to positive-class frequency, using gradient-based optimization over many passes. Performance is assessed by threshold-based classification metrics and ranking metrics.
