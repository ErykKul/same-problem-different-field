MECHANISM: The goal is to forecast a next-step continuous value of a volatile quantity from multivariate exogenous inputs, framed as supervised regression over a sliding expanding window that preserves temporal order. Several heterogeneous base learners of differing inductive biases are each trained on normalized features with cross-validated hyperparameters, and each produces a point forecast per step. Each point forecast is converted into a predictive distribution by centering a bell-shaped density at the prediction with a spread estimated from held-out residual variability, and the densities are truncated to a finite plausible interval. The interval is discretized so that each candidate value receives a probability under each learner, turning every learner into a scoring system over a common set of candidate items. Each scoring system induces a ranking, and a characteristic function is defined that maps rank back to score; the dissimilarity between two systems is the root-mean-square area between their rank-to-score curves, and each system's diversity strength is its average dissimilarity to the others. Subsets of the learners of every size are enumerated, and for each subset the candidate scores or ranks are fused by plain averaging or by averaging weighted by diversity strength, yielding many combined scoring systems. For each combination the candidate value with the highest fused probability is selected as the forecast for that step. Combinations and base learners are compared by squared-error and percentage-error metrics and by how often a combination beats the base learners across steps. The construction is purely empirical with no error bound established.
