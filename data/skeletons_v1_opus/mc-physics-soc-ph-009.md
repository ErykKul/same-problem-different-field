MECHANISM: A fixed set of nodes forms a graph whose edges change over time while the node count stays constant. Each node's connectivity count evolves as a state-dependent unbiased random walk with step size one on a bounded integer state space, where the propensity to change increases with the current count; a reflecting rule at the lower boundary forbids isolation. To decouple individual count changes from the handshake constraint, a first-in-first-out matching buffer holds nodes needing an edge and pairs them when compatible. This makes each node's count an approximately independent birth-death Markov process. In discrete time the one-step transition operator is a tridiagonal stochastic matrix; in continuous time events arrive as a non-homogeneous Poisson process with rate increasing in the count. The stationary distribution is obtained in closed form by solving the global balance equations (or equivalently the steady state of the corresponding diffusion/Fokker-Planck equation with a count-dependent diffusion coefficient and zero drift), yielding a power-law form whose exponent is set by the rate exponent. The model is then realized by event-driven stochastic simulation from a random initial graph; the empirical count distribution is compared to the closed-form prediction via information-divergence measures. Node-removal experiments (random versus highest-count-first) measure the size of the largest connected fragment and the rescaled mean pairwise path length, and recovery after removal is tracked. Free parameters are fit to empirical graphs by nonlinear least squares.
