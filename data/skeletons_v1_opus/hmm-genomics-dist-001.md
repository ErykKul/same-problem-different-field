MECHANISM: A parametric encoder maps any variable-length symbolic subsequence over a small alphabet into a fixed-dimensional real vector, so that two subsequences that overlap or are noisy copies of each other lie close under a chosen vector distance. The encoder is trained by self-supervision with a contrastive objective: for each anchor subsequence and its matching subsequence, the loss pulls their embeddings together while pushing apart embeddings of a batch of unrelated subsequences, using a temperature-scaled softmax over negative distances. A long reference string is partitioned into many overlapping fixed-length fragments whose embeddings are precomputed and stored in an index supporting approximate nearest-neighbor lookup that scales sublinearly in the number of fragments. To locate a query subsequence within the reference, its embedding is computed and the top few nearest fragment embeddings are retrieved, reducing a global scan to a local search. Each retrieved fragment is then aligned to the query by a classical dynamic-programming alignment that maximizes a match/mismatch/gap score, yielding a fine-grained offset. The global position is recovered by adding the within-fragment offset to the fragment's stored start coordinate. Encoder cost is quadratic in subsequence length from pairwise attention, retrieval cost is logarithmic in reference length, and alignment cost is the product of fragment and query lengths times the number of retrieved candidates. An optional extension orders a set of subsequences by building a neighbor graph in embedding space and traversing a low-distance Hamiltonian-style path, approximating a reconstruction of the underlying string.
