MECHANISM: Given a free-text query and optional categorical constraints, the system retrieves and ranks named entities from a large corpus of documents linked by a reference graph. The procedure is a three-stage pipeline. First, candidate documents are gathered and short local windows of text surrounding reference markers are extracted, yielding triples of source, target, and window with minimal attached attributes, optionally pre-filtered for relevance by a generative model. Second, each window is passed to an instruction-tuned generative model that outputs structured records identifying mentioned entities together with categorical role and intent labels, validated against a fixed schema by a multi-tier checker; auxiliary scalar signals such as recency-weighted usage and contextual salience are computed to complement model confidence. Third, a deterministic consolidation step canonicalizes each mention's surface string by trimming markers, removing parenthetical qualifiers and generic type words, collapsing whitespace, stripping punctuation, and lowercasing, then groups mentions sharing a canonical key while retaining all provenance and aliases and selecting a display form by frequency. The output is a ranked table of consolidated entities each carrying supporting evidence windows. Evaluation computes recall against curated reference sets under exact, canonical, and fuzzy string-matching granularities, plus a redundancy ratio measuring merge effectiveness and proportions of entities with trusted provenance and persistent identifiers. No statistical estimator or model is fit; the algorithmic core is retrieval, schema-constrained extraction, and rule-based string deduplication.
