MECHANISM: A sequential interaction is modeled as a controlled process with a hidden discrete state that evolves over discrete events according to transition probabilities depending on the current state and a chosen action. At each event a partial, action-conditioned observation is emitted from the hidden state with mode-dependent emission probabilities, and some events emit no observation. From logged sequences of actions and observations, the transition and emission parameters and the initial state distribution are estimated by an iterative latent-variable likelihood-maximization procedure: an expectation step runs forward and backward message passing to compute expected state occupancies and expected pairwise transitions, handling steps with missing observations by dropping the emission factor, and a maximization step re-estimates the parameters from these expected counts. Model order is chosen by comparing fitted log-likelihood across candidate numbers of hidden states with multiple random restarts. Given the fitted model, the agent maintains a belief, a probability distribution over hidden states, updated recursively after each event from the action and observation via the standard filtering rule. A value function over beliefs is computed by an approximate point-based solver of the recursive optimality equation that trades immediate reward against discounted expected future reward, yielding a belief-dependent action policy. Rewards combine action costs with a state-dependent benefit parameterized as an exponential of a per-state score. A separate confirmatory analysis fits a generalized mixed-effects model with a logit link and a per-subject random intercept to test the effect of actions on a binary response. The output is a learned latent-state model and an optimized policy evaluated against fixed-rule baselines.
