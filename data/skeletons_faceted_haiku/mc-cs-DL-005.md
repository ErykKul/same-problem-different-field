MECHANISM: This paper presents a computational framework for classifying research papers against Sustainable Development Goal (SDG) categories using Boolean query formulations. The method constructs Boolean queries from SDG-relevant terminology, applies these queries to abstract and keyword text to score paper-SDG relevance, and assigns papers to SDG categories based on relevance scores. Classification is deterministic and based on keyword and query matching rather than a learned model. This is primarily a classification application paper with no novel core computational innovation.
