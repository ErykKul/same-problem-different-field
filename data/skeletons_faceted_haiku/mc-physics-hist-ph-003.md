MECHANISM: Introduce assembly theory as a framework for quantifying causation in physical systems. Define assembly index (a_i) as the minimum number of recursive causal steps needed to construct an object. Model the space of possible objects as a combinatorial branching process where each step generates b possible new structures (branching factor b). Derive the Assembly Threshold Theorem using three key premises: (1) recursion (only prior structures can be joined); (2) finite resources (N total objects in a sample); (3) measurement resolution (M copies needed to detect an object type). Prove that expected copy number n(d) of objects requiring d steps decreases exponentially: n(d) = N * exp(-(b^d)) / (log(b+1))^d. Set n(a*) = M and solve for threshold a*, showing that objects with assembly index a > a* cannot form without selection. Interpret: spontaneous objects have a < a*; life and its artifacts have a > a*.
