MECHANISM: A control-affine nonlinear system is stabilized using a strict control Lyapunov function (CLF). From the CLF, a stabilizing feedback is constructed. The method introduces contractor and expander functions that are strictly increasing and satisfy specific symmetry properties around a reference value. An inverse optimal feedback is derived by composing the stabilizing feedback with the expander, and a cost function is constructed such that the composed feedback minimizes this cost while preserving Lyapunov stability. The computation involves designing state-dependent control penalties that are asymmetric relative to an equilibrium point. The method is illustrated on a predator-prey population model with harvesting control.
DOMAIN: nonlinear control systems with positivity constraints
STRUCTURE: dynamic programming
DATA_OBJECT: dense matrix or tensor
INFERENCE: optimization only
PROBLEM_FORM: optimization
DISTRIBUTION: none
