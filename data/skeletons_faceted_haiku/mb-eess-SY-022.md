MECHANISM: A hetero-functional graph-based state estimator is developed to infer flows through a network of interconnected locations from noisy observations, using a weighted least-squares optimization framework that incorporates estimation error terms into the state transition constraints. Incidence tensors representing resources, processes, and operands are constructed from geospatial data to explicitly model network connectivity and spatial topology. A measurement function assimilates empirical data (nutrient loads, delivery factors) to quantify operand flows while enforcing mass conservation and structural consistency. The estimator solves an optimization problem to recover the implicit routing structure of an existing emulator as an explicit, transparent network model suitable for systems-level integration.
