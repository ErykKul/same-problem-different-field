MECHANISM: pyBiblioNet is a Python library for network-based bibliometric analysis. It retrieves data from OpenAlex via APIs, preprocesses bibliographic metadata, constructs citation networks and co-authorship networks as graph structures, applies standard network algorithms (centrality measures, clustering, community detection), and visualizes results. Natural language processing techniques extract key topics. The paper implements and integrates existing graph algorithms and NLP methods rather than introducing novel computational approaches.
DOMAIN: Bibliometric analysis and network science
