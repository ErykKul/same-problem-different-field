MECHANISM: LongDA introduces a benchmark dataset for evaluating large language model agents in data analysis tasks. It manually curates raw data files, long heterogeneous documentation, and expert publications from 17 U.S. national surveys, extracting 505 analytical queries. The paper develops LongTA, a tool-augmented agent framework that provides document access, retrieval, and code execution capabilities. Evaluation involves executing agents on the benchmark tasks and measuring performance gaps across different proprietary and open-source models. This is a benchmark paper with no novel computational method.
