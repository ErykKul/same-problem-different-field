MECHANISM: A pre-trained black-box model is adapted to a target domain using a limited number of samples. A wrapper procedure transforms predictions from the pre-trained model and combines them with target-domain data to estimate an optimal personalization. Minimax optimal rates are established for the few-shot personalization problem. The method balances fidelity to the pre-trained model with adaptation to new data.
DOMAIN: Transfer learning, nonparametric regression, statistical learning theory
STRUCTURE: other: function approximation
DATA_OBJECT: set or table
INFERENCE: frequentist point estimate
PROBLEM_FORM: estimation
DISTRIBUTION: continuous measured distribution, none assumed
COMPLEXITY: finite-sample bound
