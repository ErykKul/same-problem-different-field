MECHANISM: Multiple LLMs are prompted to rate educational classroom transcripts on dimensions of teaching quality using provided rubrics. Pairwise concordance metrics (Kendall's tau) measure alignment between model ratings and expert human observations, and between model ratings and student learning value-added measures. Distance correlation is used to measure dependence patterns between task performance across models. A variance decomposition framework partitions misalignment error into components attributable to model choice, prompt choice, instructional task, and classroom context using a fully-crossed generalizability-theory random-effects model.
