MECHANISM: A system's information-processing order is formalized as a hierarchy from Class I (memoryless reactive mapping of input to output via a time-varying gain) through Class II (fixed transformation with internal state-dependent memory) to Class III (adaptive transformation where the operator itself evolves based on system output and history). The framework distinguishes systems by how their internal transformation rules change or remain static: reactive systems apply a gain-like function without information qualitative change; memory systems apply a fixed nonlinear transformation; adaptive systems continuously reconfigure their transformation rules via feedback from their own activity.
