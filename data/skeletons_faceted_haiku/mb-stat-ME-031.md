MECHANISM: Model time-to-event (survival) data using an additive hazard rate: h(s) = z_1 * alpha_1(s) + ... + z_r * alpha_r(s) where z_i are covariate values and alpha_j(s) are baseline hazard functions. Estimate some hazard functions parametrically (e.g., linear or polynomial forms) while leaving others nonparametric (unrestricted). Construct large-sample estimators and asymptotic confidence intervals. Conduct goodness-of-fit tests for the parametric components. Compare efficiency gains of the semiparametric model versus fully nonparametric estimation.
DOMAIN: Survival analysis and semiparametric models
STRUCTURE: other: additive model
DATA_OBJECT: sequence or time-series
INFERENCE: frequentist point estimate
PROBLEM_FORM: estimation
DISTRIBUTION: survival or time-to-event; continuous
COMPLEXITY: convergence rate
