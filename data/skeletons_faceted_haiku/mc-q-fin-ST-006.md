MECHANISM: The paper hypothesizes that an unobserved latent variable drives inflation, and proposes that observed explanatory variables are imperfect approximations of this singular process. A novel regression methodology called Latent Shock Regression (LSR) is introduced, which estimates a latent variable Phillips curve by assuming all observed variables affect an unobserved outcome with the same lag profile. The system solves jointly for a cross-sectional weight vector and a time-series lag vector using fixed-point iteration on covariance matrices. For out-of-sample forecasting, future values of the latent variable are predicted assuming first-order autocorrelation. The methodology is tested on 3,968 randomly generated factor combinations using historical US inflation data (Q1 1983 to Q1 2025), comparing out-of-sample forecast accuracy across multiple horizons.
