MECHANISM: Cover a multidimensional point cloud with non-overlapping equal-radius balls centered on sequentially selected landmarks to form a topological cover. Identify ball overlaps and construct a graph where nodes represent balls and edges represent overlaps. Color each ball node according to a function of contained points (e.g., average value of an outcome variable). Project the resulting network graph into 2 dimensions for visualization, with ball sizes proportional to point density within each ball. The algorithm preserves full data structure without dimensionality reduction while enabling visual inspection of multivariate data relationships.

STRUCTURE: graph traversal
