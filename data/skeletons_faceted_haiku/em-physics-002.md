MECHANISM: Given a set of observed lines in three-dimensional space, fit a finite mixture model in which each component is characterized by a center point, a scalar variance, and a nonnegative mixing weight, plus one extra uniform component representing outliers. The density of a line under a component decays as a Gaussian in the squared perpendicular distance between the component's center and the line. The total log-likelihood is the sum over observations of the logarithm of the weighted sum of component densities. The parameters are estimated by an iterative two-step procedure alternating until convergence. In the first step, posterior responsibilities (latent weights) are computed for each component and each observation by normalizing the weighted component densities. In the second step, each center is updated to the responsibility-weighted centroid obtained by solving a small weighted linear system built from rank-deficient projection operators that strip each line's direction, each variance is updated to a responsibility-weighted mean squared distance, and each mixing weight is updated to the mean responsibility. More components than entities are used, and components whose variance exceeds a threshold are discarded as outlier-absorbing. To track time-varying centers, observations are partitioned into overlapping time windows and a snapshot is inferred per window sequentially, warm-starting each window from the previous solution. A higher-order extension replaces each fixed center by a time-truncated Taylor polynomial, so the unknowns become coefficient vectors (position and successive derivatives) estimated jointly within each window using the observation timestamps.
DOMAIN: nuclear-imaging particle tracking, positron emission
STRUCTURE: graphical models
DATA_OBJECT: point set
INFERENCE: frequentist point estimate
PROBLEM_FORM: estimation
DISTRIBUTION: continuous; Gaussian mixture with uniform outlier component
