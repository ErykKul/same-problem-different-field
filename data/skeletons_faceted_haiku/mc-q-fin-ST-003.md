MECHANISM: A dynamic programming algorithm recursively decomposes a decision problem over time into nested subproblems using a Bellman equation. The algorithm computes the optimal value function backward in time from terminal states to the initial state, storing values for each state to avoid recomputation. Forward solutions are obtained via memoization or by solving the value function equations.
DOMAIN: Optimal control, dynamic decision making
STRUCTURE: dynamic programming
DATA_OBJECT: dense matrix or tensor
INFERENCE: deterministic or closed-form
PROBLEM_FORM: optimization
DISTRIBUTION: none
COMPLEXITY: polynomial iterative
