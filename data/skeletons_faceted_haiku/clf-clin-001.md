MECHANISM: Extract word-level and domain-specific terminology features from a collection of unstructured text documents. Compute feature frequency statistics and probability distributions for each class. Apply Bayesian probabilistic inference using the multinomial assumption to estimate posterior class probabilities for each document. Select class assignment based on maximum posterior probability. Compare multiple feature representations (words only, concepts only, hybrid) to optimize classifier accuracy.
DOMAIN: Clinical text classification and medical report filtering
STRUCTURE: graphical models
DATA_OBJECT: set or table
INFERENCE: frequentist point estimate
PROBLEM_FORM: classification
DISTRIBUTION: binary; binary
COMPLEXITY: polynomial iterative
