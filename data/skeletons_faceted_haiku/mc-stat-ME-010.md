MECHANISM: For a generalized linear regression model, decompose the overall goodness-of-fit measure into variable contributions using Shapley values from cooperative game theory. Formulate a characteristic function from a goodness-of-fit metric that measures fit for each subset of predictors. Compute the Shapley value for each predictor as the weighted average marginal contribution of that predictor across all subsets of other predictors. Extend the classical R-squared approach used in linear regression to nonlinear models by employing the Kullback-Leibler R-squared, which generalizes classical R-squared and reduces to McFadden's index for binary response models.
