MECHANISM: The paper computes statistical comparisons between groups based on cognitive test scores. It first collects data on cognitive measures (divergent thinking, cognitive reflection, insight) and demographic variables (age, sex, education). It adjusts scores for age, sex, and education using ordinary least squares regression. It then performs one-way ANOVA to compare group means (no drug use, drug use but not psychedelics, psychedelic use) on each cognitive measure. When ANOVA detects significant group differences, it applies Tukey’s HSD test for post-hoc pairwise comparisons. For insight accuracy, it calculates the proportion of insights linked to correct CRT responses. All analyses assume normality after rank-based inverse normal transformation of residuals. No domain-specific algorithms or models are used beyond standard statistical techniques.
