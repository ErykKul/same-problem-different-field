MECHANISM: The paper computes a hybrid neural network architecture to dynamically predict edge weights for a graph-based matching algorithm. The process begins by constructing a graph where nodes represent entities (syndrome defects) and edges represent potential error chains. Local features of each node are extracted using a graph neural network (GNN), which processes spatial coordinates, stabilizer types, and learned embeddings. Global dependencies across the graph are modeled using a transformer encoder, which aggregates information from all nodes and edges. The model outputs a probability for each edge, indicating the likelihood that it belongs to the true error chain. These probabilities are transformed into edge weights via a negative log-likelihood function, which are then fed into the classical minimum weight perfect matching (MWPM) algorithm. A proxy loss function, combining binary cross-entropy and entropy regularization, is used to train the network end-to-end, enabling gradient-based optimization despite the non-differentiable nature of the MWPM algorithm. The training data is generated by reducing physical error configurations to valid matchings on the syndrome graph, providing supervised signals for the network to learn. The method is evaluated on quantum error correction codes, where the predicted edge weights improve the accuracy of error correction by leveraging both local and global syndrome information. The algorithm's performance is measured by the logical error rate (LER), demonstrating improvements over standard MWPM baselines. The approach integrates classical combinatorial optimization with deep learning, allowing the neural network to refine the edge weights based on the specific statistical properties of the syndrome data.
