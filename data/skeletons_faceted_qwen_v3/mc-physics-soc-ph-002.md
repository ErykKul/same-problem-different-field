MECHANISM: The paper computes a system dynamics model to simulate interactions among policy, labor, material, and financial variables in a construction sector. The model uses stocks (e.g., number of projects, trained labor) and flows (e.g., hiring rates, permit approvals) governed by differential equations. Feedback loops are represented as causal relationships between variables, including reinforcing and balancing loops. Genetic algorithms optimize parameter values by minimizing the root mean square error between simulated outcomes and expert-weighted rankings. The process involves defining variables with initial values, parameter ranges, and units, then calibrating them through evolutionary search. Simulations test policy scenarios by adjusting intervention levels (e.g., training investment, regulatory delays) and measuring impacts on metrics like project delays and output rates. The model iteratively refines parameter estimates until alignment with empirical data is achieved, then evaluates scenario outcomes over a 20-year horizon. Sensitivity analysis tests parameter variations to identify high-leverage interventions. The computational steps include model conceptualization, parameter calibration, scenario simulation, and validation against stakeholder expectations.
