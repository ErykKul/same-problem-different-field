MECHANISM: The paper computes a graph-based recommendation system that integrates multimodal data (text and images) to predict user preferences for narrative scroll paintings. The process begins by extracting high-dimensional features from each modality using fine-tuned vision-language models, which are then probabilistically fused through a variational autoencoder to capture uncertainty in the data. These features are used to construct a graph where nodes represent users and items, and edges encode interactions. Graph neural networks perform message passing and aggregation to refine node embeddings by incorporating higher-order neighbor information. Collaborative filtering modules are integrated to refine user preferences based on historical interactions. The system uses contrastive learning to align text and image representations in a shared latent space, ensuring semantic consistency. Node classification is performed using the refined embeddings to predict user-item preferences. The final recommendation is generated by propagating information through the graph and combining it with user-specific preferences. The method handles sparse interactions by reinforcing node features and mitigating noise through probabilistic fusion. The algorithm iteratively optimizes embeddings to maximize alignment between user preferences and item characteristics while maintaining robustness to missing or noisy data.
