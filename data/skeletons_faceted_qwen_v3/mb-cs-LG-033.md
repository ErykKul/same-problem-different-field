MECHANISM: The paper computes a hybrid diffusion process that separates discrete and continuous modalities while enabling cross-modality interaction through a shared attention mechanism. Discrete tokens are processed via masked diffusion, which iteratively denoises masked entities by predicting their values based on observed context. Continuous visual latents are processed via continuous diffusion, which learns to reverse a forward stochastic process that corrupts data into noise. Both modalities are trained with specialized objectives: discrete tokens use a loss function that minimizes the negative log probability of predicted entities, while continuous latents minimize the squared error between predicted and true values. A shared attention backbone allows cross-modality interaction by applying full attention within modality-specific blocks and causal attention across blocks. During training, adaptive length augmentation introduces stochastic perturbations to response lengths, exposing the model to variable-length sequences without modifying the architecture. Inference involves block-wise generation under intra-modality bidirectional attention, where fixed conditioning blocks are cached and response tokens are iteratively generated by appending masked blocks and denoising them. The process terminates when high-confidence end-of-sequence tokens are detected, enabling flexible-length outputs. The model combines two diffusion experts—discrete masked diffusion for understanding and continuous diffusion for generation—through a unified framework that avoids gradient interference by decoupling their state spaces. Training protocols include multi-stage scaling of data difficulty and generation fidelity, with variable-length augmentation activated in later stages to improve flexibility.
