It constructs graphs where nodes represent entities and edges encode relationships between them, with edge features derived from interatomic distances and directional vectors. The model applies an attention mechanism to weigh edge contributions, using directional message passing to propagate information across the graph. Local spatial dependencies are emphasized through explicit encoding of Euclidean distances and directional vectors in attention coefficients. Residue-level features are aggregated using a learnable query vector for attention-based pooling, enhancing the capture of functionally relevant regions. Predictions are generated by mapping node embeddings to binding probabilities through a final classification layer. The model is trained to minimize prediction error across multiple interaction categories, with performance evaluated using metrics like ROC-AUC and F1-score. No explicit probabilistic modeling is performed; outcomes are deterministic. The approach generalizes across diverse molecular structures by preserving topological information in graph representations.
