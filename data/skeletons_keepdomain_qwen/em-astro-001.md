MECHANISM: The paper computes a Gaussian mixture model (GMM) to estimate miscentering parameters in galaxy cluster profiles. The method assumes that the observed galaxy density and weak-lensing profiles are generated by two components: a centered halo and a miscentered halo. The GMM likelihood is computed by convolving the true halo profile with a radial distribution of miscentered halos, parameterized by the fraction of miscentered clusters and their radial offset. The model is fit to simulated data from the IllustrisTNG hydrodynamic simulations, which provide 3D and projected 2D profiles of halos and subhalos. The likelihood function is maximized using an iterative optimization algorithm to estimate the miscentering parameters. The approach accounts for the uncertainty in the assumed cluster center by marginalizing over the latent variables representing the true halo center. The method is validated by comparing the estimated miscentering parameters to the true values in the simulations. The results demonstrate that the GMM approach provides more accurate estimates of miscentering than traditional two-parameter models. The method is applied to both 3D and 2D profiles relevant for imaging surveys. The computational steps include data preprocessing, model specification, likelihood computation, and parameter estimation via optimization. The implementation is available as a Python package with a public repository.
